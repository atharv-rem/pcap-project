# Rules for AI coding agents (Claude Code and others)

- **Never commit.** Do not run `git commit`, `git push`, `git merge`, `git rebase`, or open a
  pull request on your own. Only the human team members commit.
- Leave your changes in the working tree and tell the human what changed; they review and
  commit it themselves.
- Never add `Co-Authored-By` lines or any other AI attribution to commits, PRs, or files.
  AI agents must not appear as authors or co-authors in this repository.
- Only edit the files your member owns (see the project prompt / `docs/notes_M*.md`).
